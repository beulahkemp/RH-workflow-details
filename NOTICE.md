# NOTICE — RH-workflow-details

Data captured from RunningHub's public anonymous API (runninghub.ai / runninghub.cn) for research/archival purposes.

- All records are verbatim API responses for publicly-published workflows.
- `owner` fields (`id`, `name`, `avatar`) are public display data chosen by users for display on the platform (the compositions precedent: NOTICE-class, not account-PII).
- No authentication was used or bypassed; no private/unpublished content is present.
- Deletion requests from the upstream platform or listed owners are honored by spot-removal from this corpus on contact.
- The corpus contains NO workflow graphs (`workflowContent` is null API-side) — only public metadata inventories.
